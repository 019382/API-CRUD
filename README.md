# API-CRUD

Sobre o projeto
API REST desenvolvida em Python com FastAPI e MongoDB para realizar operações CRUD de produtos.
Tecnologias utilizadas
- Python
- FastAPI
- MongoDB
- PyMongo
Operações disponíveis
- POST /produtos — cadastra um produto.
- GET /produtos — lista os produtos.
- GET /produtos/{produto_id} — busca um produto pelo ID.
- PUT /produtos/{produto_id} — atualiza um produto.
- PATCH /produtos/{produto_id} — atualiza parte dos dados.
- DELETE /produtos/{produto_id} — exclui um produto.
Como testar
Execute a API e acesse http://127.0.0.1:8000/docs para testar os endpoints pelo Swagger.
